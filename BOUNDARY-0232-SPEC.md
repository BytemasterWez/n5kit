## Proposed contract

1. BOUNDARY.yaml is mandatory for new n5kit check/run use. Use strict JSON syntax, which is a YAML subset, so Python3.11 remains stdlib-only (PyYAML is absent there). Document the accepted subset; reject duplicate/unknown keys and malformed/incomplete policy. Include project, canon file/line references, write_paths, forbidden_paths, allowed_inputs with contract IDs, databases.allowed/forbidden_patterns, network_hosts.allowed, forbidden_imports, never_store_fields, scope_log and trusted_sockets (only docker/user-bus). Validate canonical paths/overlaps; no root/home/Work-wide grants, symlink escape or forbidden-input override. Scope-log missing or empty fails.
2. Tree scan runs on the clean extracted archive plus the complete changed files identified by the candidate commit diff. Scan tracked production code/config/data; canon, policy/scope-log and tests/documentation are identified explicitly in the checked scan contract, not ignored silently. Python import AST catches aliases; literal forbidden path/DB patterns, URL hosts and case-insensitive never-store field substrings fail. No raw matching line or secret is printed. Policy records all exemptions; explain that this is static literal/AST evidence, not proof against dynamic construction, encrypted data or malicious same-UID policy edits. Existing projects receive policy files, not unsolicited cleanup of historical findings.
3. submit loads/validates the project boundary before admission, pins its bytes/hash and project root into the private config; worker/cleanup receive that frozen policy. START/END record the boundary hash. OUT must be within a declared write path. Project source and allowed inputs mount read-only; only declared write paths are writable. Reject overlapping forbidden paths, symlinks and undeclared executable dependencies. No blanket read-only bind of / or HOME.
4. Native job and cleanup_argv run through bwrap: fresh mount/PID/IPC/network namespaces, minimal read-only OS runtime plus approved inputs/project; new proc/dev, cleared environment, no undeclared host sockets, no inherited secret environment or open fds; --die-with-parent. Explicit trusted_sockets may mount docker/user-bus, with the full host-authority escape risk recorded: these sockets are privileged capabilities, not filesystem-only grants. Keep n5kit's trusted controller outside to sample cgroups and release reservations; it is not permission for caller code to run there. Existing kill/resource/floor/expiry guarantees remain. Docker uses its existing isolated network plus read-only root, no privileged mode/host namespaces/socket and all capabilities dropped except DAC_OVERRIDE (needed by the existing root-image contract to write the uid1000-owned 0700 output), and only policy-checked mounts plus ephemeral tmpfs /tmp and /run. Its ownership repair remains narrowly trusted controller work.
5. Network — lead10:55:19 ruling: empty network_hosts.allowed means kernel DENY-ALL. A nonempty declared host list permits networking, with literal URLs/hosts statically checked against that list and the full list recorded in START/END. Runtime per-host filtering is NOT implemented: dynamically constructed destinations, localhost and host-network abstract Unix sockets (including DBus/X11) remain reachable in network-enabled native jobs. This known limit is explicit; never call this an enforced per-host firewall. Native uses the host network only for this declared mode; Docker uses its isolated ordinary bridge with egress rather than host networking. No silent adoption into current pinned jobs.
6. Files: put BOUNDARY.yaml and SCOPE-LOG.md beside existing canon in FedSpend, Calder & Rowe, FirstPass and CypherMesh N5; write only those files, no code/Makefile/pin/restart changes. County Product1 has no existing consumer repo: propose a documentation-only /home/wez/Work/county-data-snapshot with a short boundary canon, BOUNDARY.yaml and SCOPE-LOG.md; no repo initialization or implementation. Do not silently claim current jobs use these policies. New/changed policy requires a scope-log decision before implementation.
